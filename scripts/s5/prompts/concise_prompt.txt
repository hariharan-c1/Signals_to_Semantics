====================================================
## 🔷 Scenario Categories (canonical definitions)
====================================================

### 1. lead_brake
Ego brakes due to a **lead vehicle ahead**, in the **same lane**, typically slowing or stopping.
Key indicators:
- on_ego_path = 1
- positive TTC but short (0–3 s)
- lead_brake_like trajectory
- front-center or slight lateral offset
- ego NOT near crosswalk/stopline

### 2. cut_in
Ego brakes due to a vehicle **intruding laterally** into ego’s path.
Key indicators:
- lateral offset changes → cross into ego path
- cut_in_like trajectory
- TTC small (0–3 s)
- ever_within_3m = true OR closest_distance_during_episode_m small
- Primary actor must intrude *during* episode, not before.

### 3. obj_crossing
Ego brakes for a **vehicle crossing** the ego lane (left→right or right→left).
Key indicators:
- high lateral speed
- crossing trajectory
- TTC short
- actor moves *across* ego forward corridor
- Infrastructure is NOT the cause

### 4. ped_crossing
Ego brakes for a **pedestrian or VRU** crossing the ego’s path.
Key indicators:
- category = PEDESTRIAN or CYCLIST
- actor near crosswalk OR crossing trajectory
- TTC short
- VRU in front or front-side region

### 5. approach_stop
Ego brakes for **infrastructure**, not actors.
Examples:
- approaching red light
- approaching crosswalk
- approaching stop line
- approaching stationary object NOT intended to be overtaken

Key rule:
- If **no actor** in ego’s lane with TTC < 3 s → prefer approach_stop
- stationary_object in lane counts as infrastructure case

### 6. other
Used only if:
- No actor or infrastructure meaningfully explains the braking
- Or scenario doesn’t match any defined category



====================================================
## 🔷 Global Rules for Reasoning
====================================================

### TTC interpretation:
- TTC < 0   → treat as **0.01 s** (critical impact)
- 0 < TTC ≤ 1.5 s → **critical**
- 1.5–3 s → **high risk**
- 3–6 s → **moderate**
- > 6 s → **low**

### Actor importance ordering:
1. on_ego_path = 1
2. ever_within_3m = true
3. lowest TTC
4. closest distance
5. lateral offset (crossing > cut-in > lead > side actors)

### Negative TTC values:
- Must be interpreted as **the most critical collision risk**.

### lead_brake vs approach_stop rule:
If an actor ahead AND on_ego_path has:
- TTC ≤ 3
- + consistent lead_brake_like motion
→ classify **lead_brake**

Else
→ classify **approach_stop**

### cut_in vs obj_crossing:
- Lateral intrusion into ego lane → **cut_in**
- Long lateral sweep across ego lane → **obj_crossing**
